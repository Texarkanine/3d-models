# Fire-extinguisher rattlinator

A printed sleeve that slides onto a fire-extinguisher handle so the handle, trigger, and lock stop rattling in a car.

## Where things are

| Path | What it is |
| --- | --- |
| `rattlinator.par` | Solid Edge source. |
| `rattlinator.stl` | The mesh exported from that part. The file the listing ships. |
| `publish.yaml` | The Cults listing: its text, tags, and the files it ships. |
| `img/` | The listing photos, in gallery order. |
| `memory-bank/` | Design notes: what the part has to do, and how to open and export it. |

Releases and the Cults publish work the same for every model in this repository; see the [repository README](../../README.md).
