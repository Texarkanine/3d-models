# Jerry can buffer

A Solid Edge part. This directory is the 3/8 in lip. The Cults listing is still blank.

## Where things are

| Path | What it is |
| --- | --- |
| `jerry-can-buffer.par` | Solid Edge source. |
| `jerry-can-buffer.stl` | The mesh exported from that part, in millimetres. The file the listing ships. |
| `publish.yaml` | The Cults listing. Its text, license, and category are still blank. |
| `img/` | Listing photos, when there are any. |
| `memory-bank/` | Which variant this is, and how to export it. |

Releases and the Cults publish work the same for every model in this repository; see the [repository README](../../README.md).
