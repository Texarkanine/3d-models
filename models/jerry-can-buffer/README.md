# Jerry Can Cage Bumper / Buffer

A printed bumper that slips onto the frame of a metal jerry can cage so the can does not sit on bare metal.

## Where things are

| Path | What it is |
| --- | --- |
| `jerry-can-buffer.par` | Solid Edge source. |
| `jerry-can-buffer.stl` | The mesh exported from that part, in millimetres. |
| `jerry-can-buffer.step` | The same body as a STEP file. |
| `publish.yaml` | The Cults listing: its text, the fit, the print notes, and the files it ships. |
| `img/` | The listing photos, in gallery order. |
| `memory-bank/` | Design notes: the channel sizes, and how to open and export the part. |

Releases and the Cults publish work the same for every model in this repository; see the [repository README](../../README.md).
